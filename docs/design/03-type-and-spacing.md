# 03 — الخطوط والمسافات: السلّم الجديد

> الهدف: من **32 حجماً** إلى **6 أدوار**، ومن هوامش نسبية متغيّرة إلى **شبكة 8px
> واحدة** مع هامش صفحة موحّد.

---

## 1. السلّم الخطي المقترح (6 أدوار)

| الدور | px | rem | ارتفاع السطر | الوزن | الاستخدام |
|---|---:|---|---:|---:|---|
| `caption` | **12** | 0.75 | 16px (1.33) | 500 | شارات، عدّادات، تلميحات، بيانات ثانوية قصيرة |
| `body` | **14** | 0.875 | 20px (1.43) | 500 | وصف، سطر فنان/ناشر، تفاصيل قائمة |
| `label` | **16** | 1 | 22px (1.38) | 500 | أزرار، عناوين صفوف القوائم، تسميات الحقول |
| `title` | **20** | 1.25 | 26px (1.3) | 600 | عنوان قسم/لوحة |
| `heading` | **28** | 1.75 | 34px (1.21) | 600 | عنوان صفحة (إعدادات، موسيقى، تفاصيل) |
| `hero` | **40–64** | `clamp(2.5rem, 4.6vw, 4rem)` | 0.98 | 600 | اسم اللعبة في البطل فقط |

### لماذا هذه القيم؟

- **الحد الأدنى 12px**: كل ما دونه (8.32–11.84) غير قابل للقراءة من مسافة
  الأريكة، ويشكّل 94 نصاً فاشلاً في التباين.
- **الجسم 14–16px**: عند 1080p يمثّل 1.3–1.5% من ارتفاع الشاشة، وعند 720p
  يمثّل 1.9–2.2% — داخل نطاق 10-foot UI المعتاد.
- **البطل 40–64px** بدل 41.6–86.4: يقلّل الصخب في أعلى الشاشة بنحو 25% دون
  فقدان الهوية.
- **ستة أدوار لا أكثر**: أي نص جديد يجب أن ينتمي إلى واحد منها، وإلا فهو خارج
  النظام.

### الأوزان والتتبّع

| القيمة | المسموح |
|---|---|
| الوزن | **500** و**600** فقط (حذف `font-normal`/`bold` غير المستخدمين أصلاً) |
| `tracking` | **0** افتراضياً، و**0.08em** للـ`caption` المكتوب بأحرف كبيرة فقط |
| `uppercase` | للـ`caption` فقط (عناوين الأقسام، الشارات) |

يُحذف كل تتبّع آخر: `0.52em`، `0.4em`، `0.22em`، `0.18em`، `0.16em`، `0.14em`،
`0.12em`، `0.1em`، `0.06em`، `0.02em`، والقيم السالبة.

| الحالي (px) | إلى | ملاحظة |
|---|---|---|
| 8.32 / 8.80 / 9.28 / 9.60 | **12** `caption` | شارات وتلميحات |

| 10.72 / 10.88 / 11.20 / 11.52 | **12** | إن كانت تسمية قصيرة |
| 11.84 / 12.16 / 12.48 | **12** أو **14** | `caption` للشارة، `body` للوصف |
| 12.80 / 13.12 / 13.44 / 13.76 | **14** `body` | أغلب النص الثانوي |

## 3. شبكة المسافات

### 3.1 السلّم

| الرمز | px | الاستخدام |
|---|---:|---|
| `1` | 4 | داخل عنصر تحكم واحد (أيقونة↔نص) |
| `2` | 8 | بين عناصر مترابطة |
| `3` | 12 | حشو أفقي داخل الأزرار |
| `4` | 16 | بين مجموعات صغيرة |
| `6` | 24 | بين صفوف/بطاقات |
| `8` | 32 | بين أقسام |
| `12` | 48 | بين كتل كبرى |
| `16` | 64 | أعلى/أسفل الصفحة |

لا قيم خارج هذه القائمة. يُحذف `p-[2px]` و`gap-5` و`gap-7` و`pb-7` و`mt-5`
لصالح أقرب قيمة.

### 3.2 هامش الصفحة الواحد

بدلاً من `px-[6vw]` في تسعة ملفات:

```css
--page-gutter: clamp(1.5rem, 4vw, 4rem); /* 24 → 64px */
--page-max: 1600px;
```

| العرض | الحالي `6vw` | المقترح | الفرق |
|---:|---:|---:|---:|
| 1280 | 76.8px | 51.2px | −25.6 |
| 1440 | 86.4px | 57.6px | −28.8 |
| 1920 | 115.2px | 64px | −51.2 |
| 2560 | 153.6px | 64px + توسيط | مساحة أكبر للمحتوى |

الفائدة المزدوجة: الهامش يصبح ثابتاً/متوقّعاً، ويُكسب عرض إضافي للمحتوى على
الشاشات الكبيرة بدل هدره.

### 3.3 إيقاع الصفحة

```
أعلى الصفحة            32px
عنوان الصفحة → المحتوى  24px
بين الأقسام            32px
بين الصفوف             24px
بين البطاقات            12px
أسفل الصفحة            32px (48px في الرئيسية)
```

## 4. الارتفاعات والأهداف

| العنصر | الارتفاع | ملاحظة |
|---|---:|---|
| زر أساسي | **52px** | أعلى تركيز بصري |
| زر ثانوي / أداة | **44px** | حد 10-foot الأدنى |
| حقل إدخال | **44px** | — |
| زر أيقونة | **44×44** | حتى لو الأيقونة 20px |
| بطاقة مكتبة | كما هي (`clamp(8.5rem,11vw,12rem)`) | 2:3 |
| غلاف Overlay | 52px | يبقى |

كل هدف قابل للتركيز يجب أن يكون ≥ 44px في البعدين، وإلا يُوسَّع بالحشو لا
بالحجم المرئي.

## 6. المقترح التقني (للتنفيذ لاحقاً)

```css
@theme {
  --text-caption: 0.75rem;
  --text-caption--line-height: 1rem;
  --text-body: 0.875rem;
  --text-body--line-height: 1.25rem;
  --text-label: 1rem;
  --text-label--line-height: 1.375rem;
  --text-title: 1.25rem;
  --text-title--line-height: 1.625rem;
  --text-heading: 1.75rem;
  --text-heading--line-height: 2.125rem;

  --radius-control: 0.75rem;  /* 12 */
  --radius-card: 1.25rem;     /* 20 */

  --spacing-page: clamp(1.5rem, 4vw, 4rem);
  --duration-focus: 120ms;
  --duration-panel: 200ms;
}
```

ويُبنى مكوّن واحد `PageFrame` يملك:

- الهامش (`--spacing-page`) والعرض الأقصى (`1600px`).
- رأس الصفحة (عنوان + إجراء واحد + رجوع موحّد).
- منطقة المحتوى القابلة للتمرير مع مؤشر رفيع ظاهر.

هذا المكوّن وحده يزيل خمس نسخ من زر الرجوع، وثلاثة تباعدات مختلفة للعناوين،
واختلاف الهوامش بين الشاشات.

## 7. معايير قبول هذا الملف

- [ ] لا يوجد `text-[…]` بقيمة خارج الأدوار الستة في `src/renderer/src`.
- [ ] لا يوجد نص أصغر من 12px.
- [ ] عدد `tracking-*` المميزة = 2.
- [ ] عدد أوزان الخط = 2.
- [ ] لا يوجد `px-[6vw]`؛ كل الصفحات تستخدم `PageFrame`.
- [ ] كل الأهداف القابلة للتركيز ≥ 44px.
