
### التغييرات

| # | من | إلى |
|---|---|---|
| M1 | 4 تبويبات | **3 مرشّحات**؛ «All» = بلا مرشّح (الافتراضي) |
| M2 | 5 مستويات نصية في الصف | **3**: عنوان، فنان، شارة واحدة (Preview/Provider/Quality) |
| M3 | 16 حجماً | **6** |
| M4 | 21 موضع تركيز | **≤ 12 ثابت + 2 لكل مقطع** |
| M5 | إعداد يوتيوب داخل الصفحة | لوحة جانبية عند ⚙ (لا تدفع المحتوى) |
| M6 | أزرار Overlay والموسيقى والتكرار في صف واحد | صف تحكم واحد: ⏮ ▶ ⏭ 🔊 |
| M7 | لوحة Now Playing بلا ضمان عند 720p (قياس سابق: 147px مقصوصة) | غلاف `clamp` + تثبيت التحكم في الأسفل + اختبار 720p |

**لماذا دمج «All» مع المرشّحات؟** «All» ليس وجهة مستقلة، بل حالة عدم اختيار.
تحويله إلى زر ثالث يجعل ثلاثة أزرار تتصرّف كزر واحد، ويضيف طبقة تنقّل كاملة.

### الأرقام

| المقياس | الآن | بعد |
|---|---:|---:|
| تبويبات/مرشّحات | 4 | 3 + افتراضي |
| أحجام الخط | 16 | **6** |
| أيقونات | 31 | **≤ 18** |
| وسوم JSX | 297 | **≤ 200** |
| أهداف ثابتة | ≥ 19 | **≤ 12** |
| تمرير داخلي عند 720p | غير مؤكد — قياس سابق سجّل قصّاً، والغلاف صار `clamp` | **لا** |

### المقترح

```

```

| # | من | إلى |
|---|---|---|
| O1 | 28/32px | **40px** (الإغلاق 40 أيضاً) |
| O2 | 4 أحجام | **3** (14/12/12) |
